# Validation data

This directory is reserved for traceable validation evidence.

- `raw_reference_data/`: immutable source material or source-provided tables where redistribution is permitted.
- `digitized_data/`: values digitized from published figures, accompanied by method, operator, date, units, uncertainty, and source figure/table identifiers.

Published experimental data used for validation must retain full citation and provenance information. Never overwrite raw reference data. Licensing and redistribution restrictions must be respected; where a source cannot be stored, record a durable citation and retrieval information instead.
